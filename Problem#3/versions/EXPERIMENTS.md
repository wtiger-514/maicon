# Problem#3 군 장비 정비 보고서 고장 유형 분류 — 실험 기록

- 지표: Macro F1 (6클래스, 최대화). train 540 (클래스당 90), test 180.
- 핵심 관찰: train 보고서는 핵심 증상 문장 90종이 서식·장비명·부가 점검 문장만 바뀌어 약 6번씩 반복된다(핵심 증상 → 라벨 100% 일관). test 핵심 증상 95종은 **모두 train에 없는 바꿔 쓴 표현**이고, 서식(`[현상]`, `정비 메모 —`, `재현 시험에서`)과 부가 점검 문장(`동시에 점검한 항목에서는…`, `[기타]…`)도 train과 다르다.
- 따라서 무작위 KFold는 같은 핵심 증상이 학습과 검증에 함께 들어가 0.999로 과대평가된다. **핵심 증상 단위 StratifiedGroupKFold(5-fold × seed 0,1,2)**로 평가한다. 이 방식은 처음 보는 증상을 맞히는 상황이라 test(같은 증상을 바꿔 쓴 표현)보다 어려울 수 있다.
- 환경: Python 3.9.25 / numpy 1.23.5 / pandas 1.5.2 / scikit-learn 1.1.3 (서버 버전 venv), CPU 2코어 제한. 추가 패키지 없음. 노트북 실행 약 18초.

|---|---|---|---|---|
| v1 | 사용자 초안: 원문 char(2,4) TF-IDF + LR(balanced) | 0.432 ± 0.008 (무작위 CV 0.999) | 기준 | v1_baseline_raw_char24_lr.csv |

- 사전만 쓴 규칙(argmax, 학습 없음)의 train F1: 사전 v1 0.989, 사전 v2 0.989.

- test 예측 분포: v1 COMM 18~ELEC 36 / v2 ENGINE 24~ELEC 38 / 사전 v1 HYD 42, COOL 18 / **v3 27~32** (train은 클래스당 30에 해당하는 균등 분포).
- v3 vs v2 일치 88.3%, v3 vs v1 68.3%.

## 덜 낙관적인 추정: train에서만 자동으로 뽑은 사전 (2026-10-10)
- 방법: 각 학습 fold 안에서만, 한 계통의 서로 다른 핵심 증상 n개 이상에 나오고 다른 계통에는 (거의) 안 나오는 글자 2·3-gram 조각을 계통 사전으로 자동 선택 → v3와 같은 모델. 사람 지식·test 문장이 들어가지 않으므로 그룹 CV가 정직한 추정이다.

| 설정 | 그룹 CV Macro F1 | 사전 크기 (계통별) | test 예측 분포 (최소~최대) | v3 일치 |
|---|---|---|---|---|
| 핵심 2개 이상, 다른 계통 0% | 0.775 ± 0.027 | 7~21 | COOL 17 ~ ENGINE 48 | 73.3% |
| 핵심 2개 이상, 다른 계통 ≤20% | 0.804 ± 0.038 | 9~21 | COOL 14 ~ ENGINE 57 | 77.2% |
| 핵심 3개 이상, 다른 계통 0% | 0.795 ± 0.034 | 3~10 | COOL 17 ~ MOB 47 | 75.6% |
| 2-gram만 | 0.798 ± 0.028 | 4~15 | COOL 17 ~ ENGINE 57 | 69.4% |

- 결론: train만으로 만든 사전은 v2(0.789)와 차이가 노이즈 수준이다. train에는 증상 90종뿐이라 처음 보는 표현을 일반화할 만한 어휘가 모이지 않는다. v3의 0.989는 사람이 넣은 도메인 지식의 효과이며 train만으로는 정직하게 잴 수 없다.
- 정직하게 잴 수 있는 하한은 약 0.79~0.80이다. test가 클래스별 30건으로 균등하다고 가정하면(train이 균등하므로 추정, 미확인) 분포만 보고도 최소 오류 수를 셀 수 있다: v2는 최소 15건(정확도 ≤ 0.917), v3는 최소 4건.
- 결정: 메인은 v3를 유지한다. 자동 사전 버전은 이득이 없어 기각하고 파일을 만들지 않는다.

## 주의 (낙관적 추정)
- 정제 규칙(서식·부가 문장 패턴)과 키워드 사전은 **test 입력 문장(라벨 없음)을 읽은 뒤** 만들었다. 사전 v2는 test에서 사전 매칭이 없거나 한 계통으로 쏠리던 표현을 보고 일반 도메인 용어(예: 보호 경보, 자료 교환, 시간 초과, 축전, 직진·한쪽으로)를 추가했다. 정답은 사용하지 않았지만, 그룹 CV 0.989와 test 분포 균형은 **낙관적**으로 봐야 한다.
- 사전 단어 하나가 다른 계통 문장에 나오면(예: '이동하면 접속이 해제'의 '이동') 틀릴 수 있다. 사전 v2에서 '이동'은 '자체 이동', '이동이'로 좁혔다.
