# Problem#2 비행 물체 인식 (비행기·새·드론 종류와 수량) — 실험 기록

- 지표: 이미지별로 (airplane, bird, drone) 세 수가 모두 맞은 비율. **정답이 있는 검증 데이터가 없다** (전이학습 58장은 전부 드론 1대, 학습에 사용). 아래 수치는 정확도가 아니라 동작·분포 확인용이다.
- 환경: Python 3.9.25 / torch 1.10.0 (PyPI cu102 빌드, CPU로 실행) / ultralytics 8.4.175 / numpy 1.23.5 / pandas 1.5.2 / opencv-python-headless 4.10.0.84, `taskset` CPU 2코어. 노트북 전체 7분 30초 (학습 6.3분 + 추론 68초).
- 설치 주의: `pip install ultralytics`를 그대로 하면 opencv 4.11+가 numpy 2.x를 끌어와 pandas 1.5.2가 `numpy.dtype size changed` 오류로 깨진다(이 세션에서 실제 발생). 노트북은 `--no-deps`로 ultralytics를 설치하고 numpy 1.23.5, opencv-python-headless 4.10.0.84를 고정한다.

## 데이터 점검
- test 300장 (파일 내용이 같은 중복 0쌍, 평균 해시 근접 중복 3쌍: test033≈test289, test027≈test234≈test034). 크기 500×333~1280×882.
- test033, test289는 전이학습 drone_049.png와 같은 그림 → 라벨(드론 1)을 사용.

## 드론 전이학습
| 시도 | 설정 | 결과 | 결정 |
|---|---|---|---|
| probe | yolov8n, 416px, 2 epoch | 2코어에서 epoch당 약 10초 | 시간 측정 |
| t1 | yolov8n, 512px, 30 epoch, patience 8 | epoch 1이 최고 → 9 epoch에서 조기 종료 (val mAP50 0.79→0.2대로 흔들림) | 기각 |
| **t2** | yolov8n, 512px, 40 epoch, freeze=10, patience 0, batch 8, workers 0 | 6.3분, val mAP50 0.995 / mAP50-95 0.906 (val 12장은 학습에도 포함 → 낙관적) | **채택** (`drone_best.pt`) |

## 종류 판정과 수량
| 버전 | 종류 판정 | 수량 | test 종류 분포 (비행기/새/드론) | 결정 |
|---|---|---|---|---|
| v1 | yolov8s 비행기·새 최대 conf vs 드론 모델 최대 conf 중 큰 쪽 | 해당 종류 박스 conf≥0.3, NMS | 96 / 83 / 121 | 기각 |
| **v2** | ImageNet 분류기 `yolov8s-cls`: 새 클래스(7–24, 80–100, 127–146) 확률 합 / airliner·warplane·wing 합 / 나머지=드론 | 비행기·새는 yolov8s, 드론은 드론 모델. conf≥0.3, IoU 0.5·포함도 0.8 중복 제거, 최고 conf의 50% 이상, 최대 박스 면적의 10% 이상, 0개면 1 | 112 / 97 / 91 | **메인** |

- v1 기각 근거: 드론 모델은 드론만 학습해 비행기·새 사진에도 0.8~0.9 conf를 내고(예: test001, 004, 015), yolov8s는 드론 사진을 비행기로 0.9 conf로 잡는다(test011~013). 300장 중 137장은 1·2위 conf 차이가 0.2 미만.
- v2 분류기의 드론 성능 확인 (라벨 있는 전이학습 드론 58장, 분류기는 이 이미지로 학습하지 않음): 드론 51장(88%), 비행기 7장(12%, 주로 wing·warplane). → test 드론 중 약 12%가 비행기로 오판될 수 있다(추정).
- 수량 분포(v2): 1개 285장, 2개 13장, 4개 1장(test290 드론), 9개 1장(test114 전투기 편대).
- v1 vs v2: 종류 일치 83.3%, 행 전체 일치 78.3%.

## 주의 (낙관적·미검증)
- 수량 규칙(상대 conf 50%, 최소 면적 10%)은 test 이미지에 박스를 그려 **눈으로 확인한 뒤** 정했다(작은 배경 비행기, 리모컨·사람에 잡힌 드론 박스 제거 목적). 정답은 없으므로 실제 점수는 미측정이다.
- 정답에서 배경의 작은 비행기를 세는지 알 수 없다. 센다면 v2는 해당 이미지에서 개수를 적게 낸다.
